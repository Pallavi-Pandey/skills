# Module 4: Cloud Service and Deployment Models

> **Format:** Theory-led, discussion-driven — service-model comparisons, deployment decisions, and security trade-offs.
> **Builds on:** Module 3's virtualization and cloud foundations.

Cloud consumers need to decide two things: **how much of the technology stack they will manage** (the service model) and **where/how the cloud is operated** (the deployment model). This module gives a practical framework for making both choices.

## Learning Outcomes

After this module, students should be able to:

1. Compare IaaS, PaaS, SaaS, and XaaS by responsibility, control, and risk.
2. Distinguish public, private, hybrid, and community deployment models.
3. Select suitable service and deployment models for a real-world workload.
4. Explain why shared responsibility and data governance change with the model selected.
