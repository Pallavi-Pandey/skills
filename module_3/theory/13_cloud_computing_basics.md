# 13. Cloud Computing Basics

## Virtualization is an enabler; cloud is a service model

**Cloud computing** provides configurable computing resources — networks, servers, storage, platforms, and applications — as on-demand services delivered over a network. Virtualization helps implement cloud, but a manually managed VM server is not necessarily a cloud.

The commonly used NIST characteristics are:

1. **On-demand self-service** — consumers provision without a human operator.
2. **Broad network access** — services are reachable through standard networks/mechanisms.
3. **Resource pooling** — multi-tenant resources are dynamically assigned.
4. **Rapid elasticity** — capacity can grow or shrink quickly.
5. **Measured service** — usage is metered for control and billing.

> **Simple analogy:** Buying a server is owning a power generator. Cloud computing is using an electricity grid: request what you need, pay for what you use, but accept that the provider operates the infrastructure.

## Benefits and trade-offs

Cloud changes capital expenditure into operating expenditure, speeds provisioning, and can provide global scale. It also creates dependency on APIs/providers, recurring costs, data-governance questions, and the need for careful identity, network, and cost controls.
