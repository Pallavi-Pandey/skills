Distributed Computing course materials (Subject Code: 25MTCSEDE52).

- [`module_1/`](module_1/) — Introduction to Distributed Systems: hands-on labs (sockets, RPC/gRPC, concurrency, mutual exclusion, deadlocks) plus a theory reference.
- [`module_2/`](module_2/) — Fault Tolerance and Security in Distributed Systems: a theory-led module (case studies and discussion, not hands-on labs) covering fault classification, fault tolerance strategies, consistency/CAP, and the full security stack from authentication through auditing.
